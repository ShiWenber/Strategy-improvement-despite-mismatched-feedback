# 完整主矩阵：提示反馈与选择方式

本文件解释已完成的 45 条主实验轨迹。45 个独立采样对照也已完成，综合结论见 FINAL_REPORT.md；这里保留主矩阵的单独分析。

## 设计与解释范围

3 种提示（minimal、score、full）× 3 种选择方式（paper_truncation、tournament、fermi）× 5 个生成种子，全部完成 g0–g9。每种子共享初始群体；以训练 fitness 选每代冠军，保留测试不参与生成、选优或下一代更新。默认每场 100 轮、5 次重复、收益 R/S/T/P=3/0/5/1，fitness 为同代与历史档案平均累计收益的 0.6/0.4 混合。

以下收益均按每轮归一。配对差值以生成种子为统计单位，区间为五种子探索性 bootstrap 95% 区间，未校正多重比较。它们描述固定代数下整套流程的表现，不是等 token 或严格等调用量的单因素因果效应。各轨迹的群体和档案会随演化路径改变。

## 默认独立测试

| 提示 | 排名截断收益 / 合作率 | 锦标赛选择收益 / 合作率 | Fermi 收益 / 合作率 |
| --- | ---: | ---: | ---: |
| minimal | 2.7057 / 0.7634 | 2.7049 / 0.7582 | 2.6787 / 0.7448 |
| score | 2.6433 / 0.7525 | 2.6191 / 0.7271 | 2.6398 / 0.7160 |
| full | 2.5644 / 0.6841 | 2.6998 / 0.7209 | 2.6248 / 0.6260 |

每个单元均为五个种子的终点均值，默认测试全部成功。提供更多反馈并未带来一致的收益提升：score 相对 minimal 的平均差，在排名截断、锦标赛选择、Fermi 下分别为 −0.06240、−0.08580、−0.03890。前两项探索性区间分别为 [−0.11445, −0.01975]、[−0.15865, −0.00250]；Fermi 的区间包含零。

full 相对 minimal 在排名截断下为 −0.14125 [−0.25630, −0.02620]，在锦标赛选择下为 −0.00510 [−0.11140, 0.05740]，在 Fermi 下为 −0.05385 [−0.14175, 0.04055]。因此不能把全文反馈的表现概括成一个跨选择方式稳定的增益。

选择方式的差异也依赖提示。minimal 下，锦标赛选择相对排名截断仅为 −0.00080 [−0.03220, 0.04020]；full 下则为 +0.13535 [0.03495, 0.23575]，五个种子的差值均为正。这是值得进一步验证的条件依赖现象；本报告没有据此宣称已证明总体交互效应或普遍最优机制。

## 合作、长度泛化与运行失败

收益与合作必须分开解释。full/Fermi 的默认合作率比 minimal/Fermi 低 0.11875 [−0.16200, −0.06915]，但其收益差区间包含零。优化累计收益不等于优化合作率。

长局测试存在两个终点执行失败：full/paper_truncation/seed1 与 score/tournament/seed4；默认与噪声测试终点全部成功。失败保留为 null，不能当作零收益，也不能悄悄从完成数量中删除。涉及这些条件的长局配对仅有四个成功种子，存在幸存者偏差。

例如 full 相对 minimal 在排名截断下的长局收益差为 −0.21722 [−0.31144, −0.10369]，但只来自四个成功配对。minimal 下锦标赛选择相对排名截断的长局差为 −0.15775 [−0.25320, −0.06230]，来自完整五个配对。默认测试中的近似表现不能直接推广到更长的对局。

## 成本与证据边界

每条轨迹的平均记录 token 数，minimal 约 11.0–14.3 万，score 约 111.4–119.7 万，full 约 178.7–204.4 万。按同一选择方式比较，score 约为 minimal 的 8.4–10.1 倍，full 约为 14.3–16.4 倍。这里是轨迹预算口径，含共享初始响应；不能把 45 条轨迹的 token 数简单相加当作实际新增账单。去重的 API 使用量由 API_USAGE.json 单独报告。

现有证据支持“更丰富的反馈未稳定改善本测试集上的终点收益，且生成上下文成本明显增加”。它不证明提示无效、机制等价或不存在更好的组合；五种子、单一生成模型、小型固定测试集和协议修订均限制推广。独立采样对照回答相同请求预算下条件化提案是否优于无反馈提案，须结合其完整结果后再总结演化本身的价值。
