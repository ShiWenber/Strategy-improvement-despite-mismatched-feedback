# Interface Focus 定向文献调研范围

日期：2026-09-23。读者：正在撰写 LLM 直接互惠策略演化实证论文的作者。期刊解释：皇家学会 Interface Focus，严格区别 Journal of the Royal Society Interface。

RQ1：该刊有哪些论文在博弈/合作对象、信息干预方法或生成与选择的解释问题上与当前稿件相近？
RQ2：这些论文能为当前稿件提供什么具体方法、讨论及写作参照，哪些结论不能类比？
RQ3：据该刊已发表论文和官方定位，当前稿件怎样建立实际相关性，而非仅以同刊引用包装？

三路独立检索：合作与演化博弈；学习、适应与变异/选择；信息的功能价值与干预归因。主线程核对全文、交叉比较、期刊定位和文章写法。初始试搜后立即明确以上范围，后续检索不扩成一般 LLM 合作综述。

纳入：可核实确实发表于 Interface Focus，有题名、作者、年份和 DOI，至少摘要足以支持所作概括；优先全文。排除：仅在参考文献中出现、属于 Interface 或其他期刊、只有关键词但实质关系弱。题材相近与方法/理论相近分开标记，不把未检索到高度相同论文当作首次性证据。

交付：中文工作报告，给优先阅读顺序、核实后的论文链接、与当前结果的逐项对应；不擅自改写现有论文结论。局限：定向检索，非穷尽性系统综述。
