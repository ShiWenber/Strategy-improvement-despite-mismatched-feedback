# 直接互惠实验：最终报告

本轮研究已完成：三篇指定文献调研、实验方案、独立 worktree、允许 `import random` 的策略执行器、45 条主实验轨迹与 45 个请求预算匹配的独立采样对照。结果支持的主要判断是：更丰富的反馈未稳定提升未见对手上的收益；选择方式的效果依赖提示条件；本轮没有发现演化策略在默认测试上稳定优于独立采样的证据。

## 实验设置与可复现入口

工作树为 `.worktrees/direct-reciprocity`，分支 `research/direct-reciprocity`，基准提交 `a6ae52fb8c7d86fd7005ad3b9b55c9b945bed0fe`。新增文件保留在工作树中，未提交、未合并。现有框架的选择计划和模型配置被复用；声誉观测和窗口收益未沿用到直接互惠。

采用 DeepSeek `deepseek-flash`，温度 1；3 种提示 × 3 种选择方式 × 5 种子。N=12，10 次评价（g0–g9，9 次更新），默认每场 100 轮、重复 5 次，R/S/T/P=3/0/5/1。收益累计后按对手和重复平均，再按 0.6 同代、0.4 历史档案合成。完整参数出处及未由原文明确给出的工程约定见 [实验方案](EXPERIMENT_PLAN.md)。

策略只读取本场双方已执行动作历史。随机导入接入场次独立种子；`import random`、别名导入、函数内导入和命名导入均可用。测试覆盖随机复现与进程全局随机状态隔离。执行器有指令预算，但不宣称是操作系统安全沙箱。

minimal 只给游戏和父代等基础信息，score 增加成绩，full 增加群体源码与成绩。排名截断、锦标赛选择和 Fermi 使用同一变异模板；Fermi 接受事件数可变，实际调用量被记录。固定 8 种未见对手用于默认、1% 噪声、200 轮长局测试；测试不参与生成或选优。

复现命令见 [模块说明](../../experiments/direct_reciprocity/README.md)。原始请求、响应、策略、父子关系、配置、随机种子、错误和 API usage 均保存在 [结果目录](../../results/direct_reciprocity_main_v2/)。凭据仍通过外部环境文件读取。

## 提示词与选择方式的影响

完整均值、配对差值及解释见 [主矩阵分析](MAIN_MATRIX_FINDINGS.md)。默认每轮收益，minimal 在三种选择方式下为 2.6787–2.7057；score 为 2.6191–2.6433；full 为 2.5644–2.6998。

在排名截断下，score 和 full 相对 minimal 的配对收益差分别为 −0.06240、−0.14125，探索性区间均低于零。在 full 提示下，锦标赛选择比排名截断高 +0.13535 [0.03495, 0.23575]，五个种子方向一致；minimal 下两种选择方式的差值仅 −0.00080，区间包含零。这表明结果依赖具体组合，不支持单一方式普遍获胜的结论。

full/Fermi 的默认合作率比 minimal/Fermi 低 0.11875，但收益差区间包含零。合作率不能替代累计收益指标。full 的轨迹 token 预算约为同选择方式下 minimal 的 14.3–16.4 倍，未体现一致的测试收益回报。

## 演化与独立采样

对照与主实验共享同一种子的初始群体。额外候选不接收父代或绩效反馈；每个条件使用与其实际请求数匹配的候选前缀，在该条件冻结的终点群体和档案中按训练 fitness 选优，再独立测试。对照保留了条件化训练环境，比较的是条件化提案相对无反馈提案的价值，不是另一个自主演化群体。调用数匹配，tokens 和评价计算量不匹配。

下表为默认测试每轮收益的“演化 − 独立采样”，每项五个配对种子：

| 提示 | 选择 | 平均差 | 探索性 95% 区间 |
| --- | --- | ---: | --- |
| minimal | paper_truncation | +0.04980 | [−0.01430, 0.13375] |
| minimal | tournament | −0.00405 | [−0.03320, 0.02020] |
| minimal | fermi | +0.00650 | [−0.23125, 0.22295] |
| score | paper_truncation | −0.03500 | [−0.10130, 0.03135] |
| score | tournament | +0.01070 | [−0.09220, 0.10950] |
| score | fermi | −0.04985 | [−0.31245, 0.19225] |
| full | paper_truncation | −0.06795 | [−0.18335, 0.04745] |
| full | tournament | +0.03165 | [−0.04940, 0.10885] |
| full | fermi | −0.07370 | [−0.16360, 0.04310] |

九项默认测试区间均包含零，不能宣称演化稳定胜过独立采样，也不能据此证明等价。长局测试中 full/Fermi 的差值约 −0.1248，区间 [−0.252475, −0.018075]，五个配对均成功；full/排名截断约 −0.2584，区间 [−0.440500, −0.067406]，仅四个成功配对。其余对照收益差区间均包含零。全部 27 项对照比较与失败数见 [对照报告](../../results/direct_reciprocity_main_v2/CONTROL_REPORT.md)，区间见 [对照数据](../../results/direct_reciprocity_main_v2/CONTROL_ANALYSIS.json)。

## 失败、成本与局限

主实验默认和噪声终点测试均为 45/45 成功；长局为 43/45。两个长局失败是 full/paper_truncation/seed1、score/tournament/seed4，均触发既定执行预算。对照三种终点测试均为 45/45 成功。失败记为 null，成功配对的收益分析可能存在幸存者偏差，不能将失败计为零或从失败统计中隐藏。

v2 输出树新增请求记录共 2,776 条：2,587 有效、188 无效、1 次 API 错误。2,775 个已报告用量的不同响应共 47,085,308 tokens，另外 1 条错误请求用量未知。复用的 36 个历史初始响应另列 28,292 tokens，不能重复算作新增费用。上述统计不包括此前独立保存的 pilot 和停止的 v1 批次，也不等于货币账单。见 [API 使用量](../../results/direct_reciprocity_main_v2/API_USAGE.json)。

本研究是五种子、单模型、固定小型测试面板的探索性实验，所有 bootstrap 区间未经多重比较校正。随机导入规则依用户要求修改；初始化筛选、历史初始响应复用以及观察到测试失败后的恢复规则均已公开记录。不能称完全预注册、逐参数复现原论文，或据此推导 ESS、任意对手上的泛化或模型固有合作偏好。

三篇指定论文的证据与方法差异见 [综述](LITERATURE_REVIEW.md)、[本地论文研究简报](RESEARCH_BRIEF.md)、[CSRO 调研](CSRO_LITERATURE.md)、[合作论文调研](COOPERATION_LITERATURE.md)。Zotero 在工作区切换后不可调用，两篇论文使用公开原文核实，这一访问限制已在综述记录。原始本地 PDF 已归档，复制哈希与原文件一致。

450 条主实验代际记录结构审计通过，45 个对照的请求预算、候选前缀和训练选优审计通过。31 项相关单元测试通过；五个种子的初代冠军对四个基线的 20 项独立收益累计复核全部一致。结构审计与抽样复核不等于重放全部对局。训练源码指纹与冻结值一致；原环境清单的 28 个源码哈希均未变。

主要机器可读产物为 `analysis.json`、`FACTOR_COMPARISONS.json`（108 项终点比较）、`TRAJECTORIES.json`（450 条记录、180 条请求预算配对曲线）、`CONTROL_ANALYSIS.json`、`AUDIT.json` 和 `API_USAGE.json`。收益与合作图各提供代数轴、请求预算轴以及 PNG/SVG，合计 8 个图文件。请求预算曲线仅使用不超过预算的已观察检查点，不插值或外推；相同预算上限不代表实际调用数完全相同。

当前证据更支持优先保留简单提示作为后续研究基线，并针对 full 提示下选择方式的差异设计新的验证，而不是直接将更多反馈作为性能升级。新的模型、种子、对手或方法扩展属于后续实验，不是本轮已获得的结论。
