# 相近论文的结果写法与本稿调整

2026-09-20。按用户要求搜索并阅读原文，不从二手总结推断写作习惯。以下是所读论文的具体组织方式，不是声称全领域都不用置信区间。

| 论文与已读位置 | 实际写法 | 本稿采用的做法 |
| --- | --- | --- |
| [LLaMEA](https://arxiv.org/html/2405.20132v3)，§V、Fig. 2 | 先指向收敛图，再讨论模型与选择方式之间的趋势；波动通过阴影呈现 | 正文报告比较对象、方向和少量效应量；让图承担分布信息。原文标准差/方差标签不完全一致，不照搬其标签 |
| [Self-Refine](https://arxiv.org/html/2303.17651v2)，§3.3、Fig. 4、反馈消融 | 以研究问题组织段落，解释趋势，挑选少量任务数字支持论点，完整结果放表 | 将结果段落改成明确发现；不用一连串“均值、区间、p”代替解释 |
| [When Benchmarks Talk](https://aclanthology.org/2025.findings-acl.1267.pdf)，§4.2、Table 2、Fig. 4 | 先写反馈正确性及修订表现的规律，再用表格和分布图支撑 | 将行为变化和收益归因分开，避免把反馈正确自动解释为修订有效 |
| [FunSearch](https://www.nature.com/articles/s41586-023-06924-6)，摘要与方法叙述 | 以问题、生成器和可执行评价的组合解释方法 | 用于定位研究角色，不据其写法推断本研究可以省略不确定性 |

主稿仍完整保留统计信息：表 A1 收纳主次检验，图 1–4 展示不确定性，附录报告未校正区间及 Holm 校正范围。正文不重复方括号区间，不将未显著写成等效；接近阈值的合作建议比较明确标注脆弱性。结果、讨论、结论各自承担观察、解释、归纳功能，执行授权和阶段进度移入旧稿归档。
