# 阶段性发现：仅一个完整五种子对照组

数据范围：direct_reciprocity_main_v2，主实验27/45、独立对照8/45时的快照。不能替代完整提示词×演化方式比较。数值依据CONTROL_ANALYSIS.json，后续报告应以最终原始记录重新计算。

minimal + paper_truncation的5个种子终点与独立采样对照全部完成。默认100轮测试中，演化冠军减独立采样冠军的平均每轮收益差为0.0498；按种子配对bootstrap 95%区间为[-0.0143, 0.13375]。逐种子差值0至4依次为-0.04825、0.19975、0.02425、0.028、0.04525。五组测试均成功，未因测试失败剔除种子。该结果不足以断言演化在此设置下稳定优于独立采样，也不证明两者等价。

同组200轮测试的平均差为0.0448，区间[-0.197675, 0.2196]；1%噪声测试平均差为0.03，区间[-0.0401, 0.1001]。这些都是五种子探索性区间，未进行多重检验校正。

对照匹配的是各条件实际生成请求数（种子0–3各66，种子4为67，含初始化无效重抽），使用同一训练群体/HoF环境选优。它衡量条件化演化提案相对于独立提案的收益，保留训练环境条件化选择；不匹配tokens和评价计算量，也不代表独立采样自身的群体演化。不能推广为所有提示词、选择方式、模型或收益矩阵的结论。
