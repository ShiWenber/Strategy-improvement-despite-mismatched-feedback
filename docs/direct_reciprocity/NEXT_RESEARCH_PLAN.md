# 后续研究方案：行为诊断的针对性、迁移与选择

设计与执行日期：2026-09-19。**核心包 A–C 已完成；多代门槛未通过，阶段 D 不启动。** 840 次请求、60 个父代与 600 个候选的完整评价及审计已完成，结果写入 [统一论文初稿](FEEDBACK_ATTRIBUTION_DRAFT.md) 第 5 节及附录 A（2026-09-20 重排）。准确−错配的主差值接近零；S3 后准确组对父代有正收益，但没有显示优于总分组。不能将选优收益归因于诊断匹配。

2026-09-20 继续研究：已经完成固定候选池中随机采用、门控、合格池随机与排序的事后比较，见论文第 6 节及 [分析方案](ROLE_ANALYSIS_PLAN.md)。验证选择对同池随机采用有正向收益，指定分解中门控最大；原始提案、原封存选择及新增分析各自分开报告。此研究没有新增 API 或博弈调用。下一步的可验证修复正向控制、随机变异对照及跨模型/多代实验已写入论文 §7.4，尚未执行，不计作已得到的证据。

以下保留生成前的研究逻辑与预算设想，“建议”“若”等描述是原设计，不代表已执行多代。执行前原文已封存于 `results/feedback_specificity_v2/BEFORE_NEXT_RESEARCH_PLAN.md`，本文件的状态更新不修改冻结协议或结果。

## 1. 研究主线与现有依据

**核心问题：与父代具体行为缺陷相匹配的诊断，能否产生可迁移的策略修复；这种改进能否经过累计收益选优而保留下来？**

潜在题目：*从行为修复到演化收益：LLM 直接互惠策略中的诊断针对性与选择*。它是待检验的问题，不能提前写成结论。

第一阶段的出发点有三项：正确成绩相对打乱成绩的默认收益差为 −0.00152，区间较宽；诊断相对真实成绩为 +0.15596，但诊断子代仍比父代低 0.10172；事后训练选优后，诊断相对真实成绩只有 +0.02772，区间包含零。上述证据来自五个种群，支持设计后续实验，不足以证明机制或稳定改进。

特别需要修正一个解释：原始提案与选优后策略是不同的估计对象。优势变小也可能源于父代回退、截断和可改进空间变化，不能据此直接认定“选择破坏了诊断的收益”。

相关工作已经覆盖详细反馈、反思式改写、代码演化和训练—泛化差异。Self-Refine、LLaMEA、GEPA 是反馈工作的近邻；Li 与 Wang、CSRO 是代码策略演化的近邻；Chong 等是共同演化泛化评价的直接先例。本文拟增加的是**父代—诊断匹配的受控干预、具有相反行为方向的独立检验，以及固定候选池上的选择干预**。不宣称详细反馈、反馈与选择分离或训练泛化差异本身首次提出。原文与核验边界见 [相关工作比较](RELATED_WORK_COMPARISON.md)。

## 3. 阶段 A：先完成离线准备与审计

使用已有 120 个候选做开发，不产生新的 LLM 请求。旧数据用于检验实现、估计运行成本和发现测量问题，不并入后续独立复验样本。

1. 重复评价旧候选与父代，测量训练排名对对局随机流及重复数的敏感程度，区分随机波动与稳定的训练—测试排序差异。此分析只能产生机制线索。
2. 建立独立行为测试，加入持续背叛和间歇性利用情境。用 ALLC、ALLD、TFT、宽恕型策略和永久报复型策略校验测量方向；这些手写策略只校验仪器，不计入 LLM 成效。
3. 对未生成任何新候选的流程做离线演练，检查诊断错配、文本长度、父代回退、随机流、候选来源和分析公式。检查生成任务并行顺序不会改变游戏随机数。
4. 固定反馈探针、选择验证面板、最终测试面板三套资产的源码和随机种子，记录哈希及家族关系。仅源码不同不能称为家族外泛化。

冻结前交付：提示模板、所有面板与探针源码、请求清单、父代选择规则、统计脚本、预算表、失败规则和协议快照。这里先用旧样本调试测量；新的 20 个种群和新候选不用于调试或挑选有利指标。

## 4. 阶段 B：诊断针对性的核心实验

### 4.1 默认参数与样本

保持累计锦标赛基准：N=12，100 轮，5 次对局重复，无噪声，R/S/T/P=3/0/5/1，fitness 为 0.6 同代收益 + 0.4 档案收益。保留执行器与随机数规则。单步实验中的同代种群和初始档案固定，候选之间不相互加入对手池。

建议使用 **20 个新初始种群**，每个种群按真实训练成绩预选第 1、3、6 名，每个父代在每组生成 2 个候选。并列成绩按固定槽位打破；父代只选择一次，五组共享。旧五种群不作为新增独立样本。每个初始策略采用相同、无诊断的初始化协议独立生成，不在初始化阶段优化或筛选模型提示。

生成模型先保持第一阶段配置：deepseek-flash、temperature=1、相同输出上限与 thinking 设置，记录实际返回版本、时间与 usage。服务端版本变化必须单独报告，不能仅凭别名认定模型完全不变。组内外任务按种群和父代分块随机穿插，降低执行时间与处理组重合的风险。

20 个种群是建议的资源规模，不是已经完成的功效论证；尤其准确—错配诊断是新对比，不能直接套用旧五种群的准确—总分方差。正式冻结前用旧数据范围做效应大小和聚类方差的敏感性分析。若 20 个种群只够识别较大效应，就明确限制精度；不得看到新实验显著性以后不断补种子。

### 4.2 五组对照

所有组共享游戏规则、父代代码、完整种群代码和真实累计成绩；总分映射不再是本阶段的主要干预。

| 组别 | 附加信息 | 主要作用 |
| --- | --- | --- |
| A：总分基线 | 无额外诊断 | 保留与第一阶段真实成绩组的直接联系 |
| B：准确诊断 | 当前父代在反馈探针中的真实行为统计 | 候选处理条件 |
| C：错配诊断 | 其他父代的同格式行为统计，作为当前父代的诊断呈现 | 与 B 比较，检验父代—诊断对应关系 |
| D：等长背景 | 不含当前父代行为信息的游戏、执行接口背景说明 | 检查附加任务文本和长度是否足以解释差异 |
| E：合作建议 | 不含个体证据的一般合作、宽恕与恢复合作建议 | 检查效果是否主要来自普遍增加合作的方向性引导 |

B、C 使用完全一致的字段、顺序与数值精度；不添加 B 独有的优劣标签或修改建议。D、E 与 B 的附加块按冻结 tokenizer 控制在约 ±5% 长度内，保持位置与输出要求一致，报告实际长度。A 保持短基线，不宣称五组严格等 token。背景文本并非绝对中性，因此不能仅凭 B>D 就证明针对性；关键是多项对照的共同模式。

错配在每个种群的 12 个策略诊断之间作无固定点置换，随后读取三个预选父代的错配条目；不根据测试收益或故意选择“最有害”的供体。记录供体、置换和实际数值变化，报告诊断向量相同的无效错配率。无效错配仍进入意向处理主分析，不按结果删除；有效错配子集只做敏感性分析。这样也避免只对最容易被误导的父代报告结果。

完整代码有可能让模型自行发现诊断矛盾，这属于当前信息条件的真实限制。B−C 衡量提供匹配信息的外部干预效应，不等于证明模型内部存在或缺失某种因果理解。

### 4.3 为什么不只看 B−C

如果 B>C，但 B 与 A、D、E 都没有明确差异，可能只是错误诊断造成损害，不能称为有效的新修复方法。要支持“针对性信息产生额外收益”，还需要 B 相对不含个体诊断的条件有优势，并出现第 5 节预先指定的行为变化。合作建议组是一个有明确方向的控制，不能代表所有可能的通用建议。

## 5. 阶段 B 的独立行为与迁移评价

### 5.1 将两类互惠失败同时测量

反馈探针保留原有短期背叛后恢复条件，同时新增持续 ALLD 和间歇背叛条件。诊断同时呈现恢复与防御统计，避免所有反馈都暗示“多合作”。统一呈现所有探针，不根据某个父代的测试结果挑选反馈案例。

独立行为测试采用反馈中未出现的背叛时刻、持续长度、观察窗口和恢复规则。受控历史测试与从空历史开始的自然对局分别报告；前者不冒充自然可达情境。具体参数在阶段 A 冻结，此处不给尚未实现的面板贴上已验证的泛化标签。

| 失败维度 | 父代特征，仅由反馈/开发探针确定 | 独立行为结果 | 预先提出的预测 |
| --- | --- | --- | --- |
| 无法恢复合作 | 对方停止背叛后仍长期陷于相互背叛 | 恢复至连续 5 轮双方合作的时间；未恢复率；尾段双方合作率 | 准确诊断减少恢复延迟与未恢复率 |
| 容易被持续利用 | 对方持续背叛时仍长期单方面合作 | 末段自身合作率、被单方面背叛的比例和自身收益 | 准确诊断减少持续单方面合作，且改善自身收益 |

恢复时间未在窗口内达到条件者记为截尾，并另报未恢复率，不把失败样本删掉。父代两类特征用连续分数描述，预先检验特征与处理效应的交互，不看到结果后重新划分“易修复策略”。如果样本中某一特征几乎没有变化，报告识别不足，不通过挑父代制造该机制。

**最有区分度的结果是：需要恢复时更快恢复，需要防御时更少被利用。** 这不是要求每种对手都提高收益；应报告互惠恢复与防御之间的权衡。平均合作率上升本身不作为成功条件，行为相关性也不当作已识别的因果中介效应。

### 5.2 四种资产分开使用

| 资产 | 用途 | 可否进入生成提示或选择 |
| --- | --- | --- |
| F：反馈探针 | 构造父代诊断 | 只将对应组允许的诊断加入提示 |
| T：原累计锦标赛 | 默认 fitness、父代预选、训练选择 | 可以，保持基准定义 |
| V：新增选择验证面板 | 阶段 C 的另一种选择评价器 | 可用于该规则选择，不展示给生成器 |
| H：最终独立测试 | 所有组的最终收益与行为比较 | 不进入生成、接受、停止或冠军选择 |

H 的主结果设为预先冻结的平衡对手面板、100 轮无噪声条件下的平均每轮收益。面板同时覆盖可恢复互惠、持续或间歇利用、随机和有限记忆等情境，家族等权，再在家族内等权；不给最终表现最好的家族增加权重。具体实现与 V、F 分离并记录相似性。主结论限定于该定义的对手分布。

噪声 0.01、200 轮长局、最差对手收益和家族分解列为次要/探索性结果。如另做家族外测试，必须明确哪些行为家族在 T、F、V 全部缺席；参数不同或源码不同只叫参数/实现迁移。

父代和候选在 H 上使用配对对局随机流。最终评价统一先用 20 次重复以降低随机策略的测量波动；重复数不会把独立样本从 20 个种群变成几千局。H 在全部提示、候选和选择结果冻结后统一解封计算，避免中途查看后改协议。

## 6. 阶段 C：固定候选池，检查选择环节

直接复用阶段 B 的 600 个候选，新增 LLM 请求为零。每个父代、每组都有相同的两次提案；每条规则独立比较父代和这两个候选，最优候选严格超过重新评价的父代才接纳，否则保留父代。并列优先保留父代，候选间并列按固定生成序号处理。

| 选择规则 | 接受依据 | 目的 |
| --- | --- | --- |
| S1：原训练选择 | 原同代/档案、原权重、5 次重复 | 保留累计锦标赛默认基线 |
| S2：重复训练选择 | 同一对手和权重，20 次重复 | 检查增加评价重复后决策是否改变 |
| S3：验证面板选择 | V 上预先固定的平衡收益，20 次重复 | 检查改变选择分布能否保留可迁移收益 |

S2、S3 为每个策略匹配双边对局总次数，V 的对手数按 T 的实际计分对手数配置并在冻结时检查；S3 对手分布及权重的改变是明确干预。S1 计算量较少，因此 S3−S1 不能单独归因为分布变化。S1 与 S2 使用独立于原父代预选的评价随机流，S1 的 5 次重复作为 S2 的预定子集。所有选择使用配对的父子对局随机数。

并列报告三个对象：

- 原始提案：所有提案相对父代的 H 收益，包括部署回退。
- 选优产物：各选择规则产出的最终策略相对父代的 H 收益。
- 选择诊断：接受率、规则之间的决策分歧、接受后 H 退化比例、未改变代码比例和失败率。

关键交互定义为 **I = (B−A 在 S3 后的收益差) − (B−A 在 S2 后的收益差)**。按种群配对估计。如果 I 没有明确差异，就不声称改变选择分布特别帮助诊断组。另比较 S1 与 S2，判断原结果对重复评价预算的敏感性。

H 只用于评估上述冻结规则，不用于选出一个“最佳候选”作为部署结果，也不用于在多种选择器中事后挑赢家。S3 目前是待检验的评价器，不预先命名为“鲁棒选择器”。

## 7. 阶段 D：有条件的多代检验

核心单步实验完成后，根据第 9 节规则决定是否投入。新的多代实验使用独立初始种群；旧 45 条轨迹不计为新诊断方案的多代验证。

建议的后续因子设计：**2 种反馈（A 总分、B 准确诊断）×2 种选择（累计训练收益、V 收益）×10 个新种群**。每条轨迹仍 N=12、每次替换 6 个、g0–g9 共 10 次评价/9 次更新。对每个种子共享初始种群，再让四个条件独立演化；父代诊断每代重新计算。训练收益和 V 选择条件的评价对局预算匹配，档案更新规则固定并记录。

主端点是预先规定的最终代输出在新冻结 H 上的收益；最终策略按各自的选择评价器确定，不能按 H 选冠军或最好代。群体平均收益、合作率、多样性、历代曲线是次指标。累计基准的原始 5 次重复轨迹可保留作参考，但不能与 20 次重复条件混称等评价预算。

若要进一步宣称迭代反馈优于简单增加采样，还须加入请求数匹配的无迭代独立生成基线：每个种子生成 54 个额外独立策略，从初代与新策略的并集中分别按两种选择评价器选输出。两种选择器复用该候选池，不增加生成调用；累计本地评价成本另计，若不匹配就不宣称等总算力效率。

这一阶段检验跨代累积，不用于补救阶段 B 不支持针对性的结果。10 个种群同样是预算建议，不能保证检测微小交互。第二模型属于后续外部复验，优先复验五组核心设计；未做前将结论限定在已测模型与版本。

## 8. 统计协议与失败规则

主估计量：每个种群内部先平均三个父代、每个父代两次生成的 H 收益增量，再比较 B−C；推断单位为独立初始种群，共 20 个。主对比双侧，不预设准确诊断必然更好。

预定次比较为 B−A、B−D、B−E 的原始提案差，以及 S3 下 B−A、S3 下 B 相对父代的净收益、选择交互 I，共六项。该家族使用 Holm 校正，并同时报告效应量、区间和种群级散点。主对比与次对比分开标明，不能从一串未校正比较中选显著项。

区间按种群聚类计算；配对随机化/置换分析必须对应实际的组别随机分配记录及其假设，不能因为有相同 draw 编号就假定共享 API 随机数。行为交互、噪声、长局、家族分解与父代特征分析均完整报告并标为探索性；它们可以支持解释，但不代替主要收益结果。机制确认若需要额外行为主检验，应在生成前升级协议并固定多重检验方案。

建议将 **每轮 0.05 的收益差**作为资源决策的实际意义阈值 δ。这是本研究提出的工作阈值，尚不是领域共识或已估计的最小可检测效应；正式冻结前确定。区间跨零不证明等效，排除大效果也不等于证明任何效果都不存在。

语法、接口或运行无效的候选不补抽；按父代回退计入原始提案和选择产物，同时单列无效率及有效候选敏感性分析。初始化异常使用冻结的固定回退策略填槽并记录，避免只保留容易生成的种群；若初始化质量异常，整体暂停排查，不有选择地删除不利种群。网络错误、计费状态不明与策略执行失败分开记录，未知状态不自动重试。明确报告实际请求数、输入/输出 tokens、本地对局数和成功率。

## 9. 推进、停止与改写故事的条件

| 观察到的结果 | 科学解释与下一步 |
| --- | --- |
| B>C，且 B 优于 A/D/E，独立行为呈现对应修复 | 支持匹配诊断的增量价值；进一步检验选优后的净收益与多代累积 |
| 只有 B>C，其余优势不清楚 | 支持错配可能有害；不将此包装为诊断修复成功 |
| B 与 E 接近，收益主要伴随普遍增加合作，持续背叛下损失增加 | 合作引导与权衡仍是主要解释；不宣称针对性机制 |
| B 提案更好，但 S1–S3 输出均无稳定净改进 | 聚焦提案质量与可部署输出的差距，暂停昂贵多代扩展 |
| S3 输出更好，且 I 支持差异 | 支持特定选择分布更能保留诊断收益；仍不等于普适稳健性 |
| 区间很宽 | 结论为精度不足；后续若增加独立批次，另立协议，不能将按显著性追加样本伪装成固定样本实验 |
| 相关效应区间已排除 δ 以上收益 | 对当前设置停止高成本扩展，保留负结果及其适用边界 |

进入阶段 D 的建议预算门槛：主比较 B−C 的 95% 区间下界高于零且点估计至少 δ；B 对非个体信息条件的次比较经校正后支持优势；S3 下 B 相对父代有正净收益支持。行为检查还须排除明显的普遍合作偏移解释。这些是推进门槛，不是达到后即可宣布机制已被证明。若仅少量样本导致不确定，先报告不确定性，不能自动启动大矩阵。

## 10. 预算和执行顺序

| 工作包 | 计划新增 LLM 请求 | 本地工作与限制 |
| --- | ---: | --- |
| A：旧结果重评、探针开发、冻结 | 0 | 本地重放、校验、测量资产和审计 |
| B：20 个新初始种群 | 20×12 = 240 | 所有处理条件共享；无效回退单列 |
| B：五组单步候选 | 20×3×2×5 = 600 | 最小推荐的完整对照包 |
| C：固定池选择检验 | 0 | 复用 600 候选，新增训练、V 与 H 对局 |
| **推荐先完成的核心包 A–C** | **840** | 已全部完成；实际 5,917,619 tokens |
| D：新多代初始化 | 10×12 = 120 | 四个条件共享，与 B 的种群独立 |
| D：四条件演化 | 10×4×9×6 = 2,160 | 通过推进门槛后另行执行 |
| D：请求数匹配独立采样 | 10×54 = 540 | 两个选择器共享池 |
| **完整多代扩展 D** | **2,820** | 门槛未通过，不启动，实际新增请求 0 |

按第一阶段 120 次响应共 1,071,025 tokens 粗略外推，600 次候选生成约为 **536 万 tokens**；新初始化的 240 次另计。新代码长度和诊断格式会改变输入量，这只是资源量级估算，不是费用报价或 token 上限。实际货币预算需按执行时的模型计费与冻结提示长度计算，不能把旧均值当作硬上限。

优先级：完成 A → 冻结 B/C → 一次执行核心包 → 解封 H 并更新草稿 → 根据结果决定 D。现在不扩展提示风格×选择算子×模型的大矩阵，也不把第二模型、多代和更多对手同时加入首轮，避免每个问题都只有少量独立种群。
