# 思考模式 384K 配对补充实验（2026-09-23）

用户授权：开启思考模式做一轮对照实验。最新配置要求：输出上限精确设为 384000 tokens，默认 API 并发为 50。

## 执行前固定的设计

- 复用 feedback_specificity_v2 的 20 个种群、60 个父策略、五种反馈、两次生成，新增候选请求 600 次；不重新初始化，不启动多代演化。
- 逐字复用既有 600 条提示词和请求顺序。仍要求最终 content 只输出策略源码；原生 reasoning_content 单独记录，不加新的显式反思提示，不把推理文本交给策略执行器。
- model=deepseek-flash；thinking.type=enabled；reasoning_effort=high（官方默认强度，显式固定）；max_tokens=384000，按用户指定的精确数值设置。预算是上限，不是必须生成的长度，包含思考与最终回答。默认 API 并发为 50。
- temperature=1 保留在请求中，但官方明确其在思考模式不生效；不宣称有效采样温度相同。top_p 不额外设置。
- 流式接收并保存原始事件、reasoning_content、content、finish_reason、usage、返回模型名称、请求时间和指纹。禁止自动重复未知状态或失败请求；无效程序、截断及执行失败沿用父代回退，不因结果差补抽。
- 用第一条正式候选请求验证接口是否接受 384000 及是否返回思考字段，该条计入 600 次，不额外试抽。配置不支持或没有思考证据时停止后续派发并调查，不静默缩小预算。
- 复用冻结执行器与 S1/S2/S3 评价函数、对手及随机流。父代选择成绩可复用；600 个新候选全部完成训练/验证评价和 900 项选择封存后才释放 H。
- 测试沿用默认、1% 行动噪声、200 轮长局和行为探针。旧 H 已被研究者看过，因此本轮是既有面板上的后续验证，不称全新盲测；生成与选择代码仍不得读取 H。

## 预先指定的分析

以 20 个种群为配对统计单位，不以候选数充当独立样本量。

本次两个重点比较为：(1) 思考模式内原始提案 accurate−mismatched；(2) 该差值相对历史非思考模式的变化。对这两个检验作 Holm 校正，报告效应量、种群方向、精确配对符号交换检验和种群 bootstrap 不确定性。跨时间配置比较不能视为随机分配思考模式的因果检验。

其他反馈对照、S1/S2/S3 筛选后收益、行为响应、无效率、实际推理用量与历史差异均作为补充探索。正文用效应和机制组织，完整区间留在结果文件。历史原始结果与冻结代码不改写。

本轮同时改变原生思考模式、输出预算和服务端有效采样规则，且不是同期随机化两模式。服务端模型别名也无法保证权重跨日期不变。因此只能比较这两套实际配置；不能单独识别思考开关、预算或模型版本各自的因果效应。未发现差异也不等于证明无效或等效。
